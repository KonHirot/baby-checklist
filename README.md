# 出産・育児 準備チェックリスト 👶

出産に向けた準備・お買い物・出産後の行政手続きを、ひとつずつチェックしながら進められるアプリです。
スマホでもPCでも見やすく、インストール不要で使えます。

## 使い方

1. `index.html` をダブルクリックしてブラウザで開くだけ。
2. **出産予定日**は初期値 `2026/9/25` が入っています（変更も可能）。
3. 生まれたら **出産日** を入力すると、行政手続きの期限が出産日を基準に自動計算されます。
4. チェックボックスを押すと進捗バーが更新されます。

スマホで使いたいときは、このファイルをスマホに送ってブラウザで開くか、
ホーム画面に追加しておくと便利です。

## 機能

- **カウントダウン**：予定日／出産日までの残り日数を大きく表示
- **3つのカテゴリ**
  - 🧳 出産準備（手続き・段取り）
  - 🛒 買い物リスト（ねんね・授乳・おむつ・衣類・沐浴・おでかけ・お世話・ママ準備）
  - 📄 行政手続き（出産後）
- **優先度バッジ**：`必須` / `推奨` / `あると便利` で色分け（各カテゴリ内は優先度順に並びます）
- **目安個数**：買い物項目に「目安 5〜6枚」などを表示
- **期限目安**：日付を基準に「◯月◯日まで（あと◯日）」を表示。期限が近い・過ぎたものは色で強調
- **該当なし**：地域や状況によって不要な項目（陣痛タクシー未対応地域、里帰りしない等）は「該当なし」ボタンで対象外にできます。進捗の分母から外れるので、100%を目指せます（「戻す」でいつでも復活）
- **フィルタ**：「未完了のみ」「必須のみ」で絞り込み
- **リセット**：すべてのチェックを外す（日付は残ります）

## データの保存について

- チェックの状態や入力した日付は、**この端末のブラウザ内（localStorage）にのみ保存**されます。
- サーバーには送信されません。他の端末やブラウザとは共有されません。
- ブラウザのデータ（サイトデータ）を消去すると、チェック内容も消えるのでご注意ください。

## ご注意

期限・個数・届出先・優先度は、あくまで**一般的な目安**です。
お住まいの自治体・勤務先・産院によって条件や必要書類が異なります。
**必ず各窓口や産院で最新の情報をご確認ください。**
